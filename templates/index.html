About this project

This website uses a Naive Bayes machine learning algorithm. The email text is converted into numerical features using TF-IDF, and the trained model predicts whether the message is spam or not spam.

01InputPaste an email message.
02ProcessingTF-IDF converts words into numbers.
03PredictionNaive Bayes classifies the message.
Made as a beginner-level CSE (AI & DS) mini project
